# Acceptable use

## AU-1 Work accounts

Company work is done in company accounts. Forwarding customer records to a personal inbox is not allowed.

## AU-2 Secrets

Passwords, API keys, and access tokens are not written into documents, tickets, or chat. Point to the secret store instead.

## AU-3 External sharing

A file that contains customer data is shared outside the company only with a signed agreement that covers that data. A public link is not an agreement.
