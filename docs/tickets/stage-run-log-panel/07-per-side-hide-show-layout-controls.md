# 07: Per-side hide/show layout controls

**What to build:** Extend the existing single "hide workspace" toggle into independent per-side controls, so the operator can hide either the conversational transcript or the new log panel to let the other take full width.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] The transcript side can be hidden independently, giving the log panel full width.
- [ ] The log panel side can be hidden independently, giving the transcript full width.
- [ ] Both sides can also be shown together (the current default two-column view).
- [ ] Existing behavior for any other page/component relying on the old single toggle is preserved or intentionally updated, not silently broken.
