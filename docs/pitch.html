Act One — The Problem

Every handoff
is ad hoc.

  • One long chat, or copy-pasted context between sessions
  • Every handoff is a shell script or a re-explained transcript
  • Artifacts get lost; context goes stale
  • The same flow can't run on a laptop, in CI, and via automation without a rewrite

Stripe, Shopify, and Cloudflare already built private fixes for this — Minions, Roast, and an Astro issue-triage factory.

Act One — The Fix

Stages are the unit
of composition.

  • Author a workflow as plain YAML — a pipeline of stages
  • Each stage runs in a fresh agent session
  • Stages hand off through a typed envelope
  • A human gate can pause the run anywhere

Act One — In Practice

The same pipeline, everywhere.

  • sf run locally
  • sf run --json in CI, with predictable exit codes
  • MCP from other tools
  • sf ui — local operator console: watch runs, answer gates, manage providers
