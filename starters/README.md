# Starter pipelines

Four small pipelines to try Stageflow with. Each one runs as is, with the model you connected, and needs no other accounts or setup.

| Starter | Stages | What it shows |
|---------|--------|---------------|
| [topic-brief](topic-brief/) | 1 | Task input, structured output, saving a file |
| [draft-with-approval](draft-with-approval/) | 2 | Pausing for your approval before the run goes on |
| [parallel-research](parallel-research/) | 5 | Stages that run at the same time, and a stage that waits for all of them |
| [triage-and-route](triage-and-route/) | 4 | Sending a run down one path or another based on a stage's output |

Each folder has a README with what to try and how to make it your own.

These are your files: edit them, copy them as the start of your own pipelines, or delete the folder when you no longer need them. Stageflow does not add them again.
